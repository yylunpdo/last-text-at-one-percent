The funniest final text a dying phone sends at one percent battery — in the phone's own voice, under 200 characters. It survived 47 drops, one toilet, and its owner's 3am doomscrolling, and spends its last breath forgiving the charger. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

This writes the last text to `/output/entry.txt`.
